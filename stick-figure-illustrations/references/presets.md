# Presets

Use presets to choose the right canvas, density, labels, and delivery style.

## `article`

- Use for: blog posts, essays, long-form notes.
- Canvas: default `16:9`; use `3:2` only when requested.
- Default count: 3-6.
- Labels: default to one expressive title or punchline plus key object/state labels.
- Best patterns: Before/After, Obstacle, Container, Workbench, Trade-off, Loop.
- Goal: help the reader pause at important cognitive turns.

## `newsletter`

- Use for: email essays, weekly updates, curated digests.
- Canvas: default `16:9`; use `2:1` only for an explicit email header.
- Default count: 1-3.
- Labels: expressive but readable; use punchline, state words, and 2-4 object labels.
- Best patterns: opener metaphor, Container, Signal-Noise, Loop, Obstacle.
- Goal: add rhythm without making the email feel heavy.

## `carousel`

- Use for: LinkedIn, X, Threads, Xiaohongshu, Instagram.
- Canvas: `4:5` or `1:1`.
- Default count: 5-8 pages.
- Labels: one short page headline plus 2-4 supporting labels per page.
- Best patterns: Path, Before/After, Checklist, Obstacle, Map.
- Goal: one page, one action, one thought.

## `slides`

- Use for: PPT, Keynote, talks, workshops.
- Canvas: `16:9`.
- Default count: 3-8.
- Labels: light but clear; use section words, contrast labels, or a single punchline.
- Best patterns: chapter opener, concept beside a point, Zoom-in, closing action.
- Goal: support the speaker, not replace the slide.

## `product-doc`

- Use for: docs, onboarding, how-to pages, help centers.
- Canvas: default `16:9`; use `3:2` or transparent spot illustration when requested.
- Default count: 2-5.
- Labels: product-task labels, state labels, current step, and result labels.
- Best patterns: Path, Hand-off, Obstacle, Checklist, Success state.
- Goal: make a user task or system state feel obvious.

## `saas-state`

- Use for: empty states, error states, permission states, loading, success.
- Canvas: `1:1`, `3:2`, or transparent spot illustration.
- Default count: 1.
- Labels: light by default: 1 short state title plus 1-3 object/action labels; use no text only when the user asks or localization is a hard constraint.
- Best patterns: Empty table, blocked door, waiting path, Checklist, Container.
- Goal: fit inside a UI while still explaining the state.

## `course`

- Use for: tutorials, lessons, worksheets.
- Canvas: `16:9` or `4:3`.
- Default count: 4-10.
- Labels: step labels, action verbs, common-mistake labels, and result labels.
- Best patterns: Checklist, Practice loop, Feedback loop, Common mistake, Zoom-in.
- Goal: make learning actions concrete.

## `readme`

- Use for: open-source README, contribution guide, release notes.
- Canvas: default `16:9`; use `2:1` only when requested.
- Default count: 2-4.
- Labels: clear engineering labels such as install, config, issue, PR, release, maintainer.
- Best patterns: install path, issue triage, PR hand-off, Checklist, release pipeline.
- Goal: keep an engineering-document tone, not a marketing tone.

## `thumbnail`

- Use for: video, podcast, event topic, article hero concept.
- Canvas: default `16:9`; use `1:1` only when requested.
- Default count: 1-3 options.
- Labels: one short title if needed.
- Best patterns: strong metaphor, single obstacle, trade-off.
- Goal: create a concept draft, not a finished poster.

## Brand Color

When the user provides a brand color, use it as the only accent color.

Accept:

- color names: green, blue, orange, purple
- hex values: `#22c55e`, `#2563eb`
- product terms: “use my brand green”

If no accent color is specified, choose one calm accent color that fits the content. Do not introduce a fixed palette.
